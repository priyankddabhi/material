# Motion lessons from Instagram reels

Eight motion-design reels, each watched frame by frame and written up: visuals, motion, fonts, timing, why it feels premium, and what to copy or skip.
Creator usernames are removed; each file keeps the reel link as its source.
The "Takeaway" sections use our first project (a finance explainer about Nvidia) as the example; the mechanics apply to any video.

## Rules all 8 reels agree on
- Something moves every 0.5–1 s; a new element arrives every 1–3 s; a scene holds 2–4 s.
- One focal point per frame, lots of empty space, one accent colour only.
- Hierarchy by size and weight, not by many fonts: tiny lead-in, huge hero word.
- Entrances ease in and settle (overshoot, then rest); no hard flashing.
- Change the background only at a section break.
