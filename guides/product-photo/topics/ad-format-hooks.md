## REEL-006 — 2026-10-29 — reel DdeH6agIzty (content cheatsheet)
RULE: An ad works when format + tonality + attention trigger are chosen
deliberately — not one default style every time.
FORMATS (from the reel's cheatsheet): talking-head, walking/frame-change,
short + long B-roll, reaction, whiteboard, podcast hook, rating,
this-or-that, problem-vs-solution, myth-vs-fact, true-or-false,
desktop explainer, Q&A, humour/skit, split-screen, tutorial-in-practice.
TONALITIES: serious (expert), concerned (caring), loud/excited
(attention), casual (authentic), angry (motivating).
ATTENTION TRIGGERS: emotion, curiosity, relevance, novelty, value,
social psychology. Curiosity tools: mystery, information gap, secret,
question, open loop, suspense. Value tools: utility, money, time,
knowledge, solutions, hacks, frameworks.
APPLY TO OUR ADS (honest limit: this reel teaches format + hook/text,
NOT still-photo craft — no light, colour, or composition instruction):
- For video ads: B-roll/tutorial montage of the product being made or
  used, vertical, with a short curiosity hook in the first seconds
  (withhold the result till the end = open loop).
- For still ads: the headline must carry an attention trigger — curiosity
  (question/secret/open loop) or value (utility/hack) — not just a plain
  product label.
CHECK: name the format + trigger before making the ad. If the headline
is just the product name, it has no trigger — rewrite it.

## REEL-009 — 2026-10-29 — reel DfA1t-xzM4F (9 carousel types)
RULE: Pick ONE carousel type and build every slide around that single
structure. Never mix types in one carousel.
THE NINE TYPES: step-by-step, list, storytelling, hot take,
breakdown/case study, save-for-later, news, eye-candy/showcase,
this-vs-that.
STRUCTURE (from the reel's posters): HOOK cover first → one clear
idea/moment per slide → single CTA slide last. Same bold title, large
type, and consistent background colour across all slides.
APPLY TO PRODUCT ADS: instead of one product photo alone, make a
carousel: HOOK cover (product in use, bold) → one slide per step/idea
(e.g. candle: hero → clean-burn steps → lit/unlit + detail shots) →
This-vs-That slide (handmade vs generic) → one CTA slide.
CHECK: name the type before designing. If you cannot name it in one
word, the carousel has no structure — pick one and rebuild.
