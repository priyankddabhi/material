## REEL-001 — 2026-10-29 — reel DeUYA-mxQub (one eye-start)
RULE: Give the eye ONE clear place to start.
APPLY IN PROMPT: "one hero product, largest in frame, centre; soft spotlight
glow behind hero; exactly ONE bright contrasting colour against muted tones;
all other elements subordinate, small, quiet."
APPLY IN FRAME: brand top small, headline one line, CTA one line — never
two big texts competing.
CHECK: if two elements fight for attention, shrink one. If colours blend
into mud, make one brighter.
EXAMPLE: teaching demo candle — huge candle centre, warm glow, amber flame
as the only bright colour. File: product-shoot/teaching/teaching_ad_final.png

## GIT-001 — 2026-10-29 — github.io design & layout doc (grid)
SOURCE: https://triscialehmann.github.io/DAL.pdf
RULE: Put key elements ON grid lines / intersections, not randomly placed.
APPLY IN PROMPT: "hero on a grid intersection, generous margins, clear
structure; limited colour palette; clean readable type."
CHECK: hero dead-centre every time looks static — offset hero to a thirds
intersection when the frame allows, keep margins clean.

## GIT-002 — 2026-10-29 — poster layout guide (proximity + whitespace)
SOURCE: https://kindatechnical.com/effective-communication-engineers/designing-technical-posters.html
RULE: Group related items together; whitespace separates sections; never
crowd. Visual hierarchy = size + colour + placement, never equal emphasis.
APPLY IN PROMPT: "one product group, breathing room around it, no clutter
behind small text; background clean where text will sit."
APPLY IN FRAME: headline, then CTA, then nothing — no extra badges/lines.

## GIT-005 — 2026-10-29 — penpot principles (hierarchy fix order)
SOURCE: https://skilld.dev/gh/github/awesome-copilot/penpot-uiux-design
RULE: When hierarchy fails, fix in this order: 1) size, 2) colour/contrast,
3) position, 4) whitespace isolation, 5) type weight. Do not change all
five at once.
APPLY: if a demo's eye-start is unclear, first enlarge the hero, then
raise contrast, then move it, then clear space around it — stop as soon
as the eye lands correctly.
CHECK: name the single fix applied. If you changed everything, you
learned nothing — revert and fix one thing.

## WEB-001 — 2026-10-29 — ad layout frameworks (eye-flow path)
SOURCE: https://fastercapital.com/content/Visual-hierarchy--The-Psychology-Behind-Visual-Hierarchy-and-Consumer-Behavior.html
RULE: Eye path must be product → benefit → action, no friction. One
headline + one CTA only. CTA in a high-contrast colour (reported up to 32%
better conversion). Whitespace amplifies focus, it is not emptiness.
APPLY IN FRAME: headline = benefit in one line; CTA = one short action,
visually distinct from headline (letterspaced caps).
CHECK: read order test — product first, headline second, CTA third.

## REEL-003 — 2026-10-29 — reel DcmJhPDI-Kj (contrast pairings)
RULE: Pair two contrasting elements that each look merely good alone —
the combination looks iconic, interesting, timeless, or intimate. Contrast
IN COMBINATION transforms a visual, not any single effect.
PAIRS FROM THE REEL: black-and-white + one colour pop = iconic; blur +
grain = much more interesting; vintage photo + modern type = timeless;
low exposure + warm intimate element = intimate. (Note: the 4th pair's
second element was unclear in the audio — do not guess it; the usable
rule is low, warm, intimate light.)
APPLY IN PROMPT: "product mostly neutral/muted + ONE strong colour pop
(coloured soap, gemstone, candle flame); slight blur/grain for texture,
not a clinical packshot; vintage-soft photo + clean modern frame type;
low warm candle-like light + tight intimate frame for evening/candle/
skincare ads, never flat bright light."
CHECK: if the ad has only one visual idea (all sharp, all bright, all
one colour), add its contrast partner. If it has three competing ideas,
remove one — a PAIR, not a crowd.
