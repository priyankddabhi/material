# BRAND IDENTITY / CONSISTENCY — mind topic

## REEL-008 — 2026-10-29 — reel Decz1K3sLpk (one theme, repeated)
RULE: A brand becomes recognisable by ONE clear theme carried
consistently — same motif, same palette, same wording — across every
design. Not a new unrelated image each time.
SEQUENCE FROM THE REEL (strawberry theme): busy literal strawberry
pattern → strawberries arranged in a heart-like shape → ONE single
centred strawberry on plain cream. Same red-and-cream palette and same
"strawberry season" wording throughout; simplicity increases, identity
stays.
APPLY TO A PRODUCT SET: pick one hero motif and repeat it exactly in
every photo/ad of the set: same plain background, same accent colour
taken from one single seasonal prop (not a cluttered table), same
simple serif product word in the same position, same frame style.
NEVER: change backgrounds and props shot by shot — that makes six
different brands, not one recognisable brand.
CHECK: lay the set side by side. If they don't look like siblings,
the theme broke — find where it changed and restore it.
