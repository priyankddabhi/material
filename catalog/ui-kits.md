## 📋 THE 30-REPO MASTER LIST (numbered)

### 🅰️ React — modern, Tailwind-based
**1. shadcn/ui** — https://github.com/shadcn-ui/ui — ⭐ ~123k · Since 2023 · 🟡
Special: Copy-paste components into YOUR repo (built on Radix + Tailwind). You own 100% of the code, tiny bundles, works with Next.js server components & AI tools.
Use: Any new React/Next.js website or app. The industry default.

**2. Tailwind CSS** — https://github.com/tailwindlabs/tailwindcss — ⭐ ~97k · Since 2017 · 🟢
Special: The utility-first CSS framework — the foundation of nearly every modern kit above.
Use: Learn this first; unlocks 90% of other tools.

**3. daisyUI** — https://github.com/saadeghi/daisyui — ⭐ ~42k · Since 2020 · 🟢
Special: Pure-CSS component classes (btn, card, navbar…) on Tailwind. Zero JS, 30+ one-class themes.
Use: Fastest prototyping; static HTML/CSS, Astro, WordPress, any framework.

**4. Chakra UI** — https://github.com/chakra-ui/chakra-ui — ⭐ ~41k · Since 2019 · 🟡
Special: Composable components + clean design-token theming. Famous great DX.
Use: React apps where styling must stay readable and customizable.

**5. Mantine** — https://github.com/mantinedev/mantine — ⭐ ~32k · Since 2021 · 🟡
Special: 100+ components AND 100+ hooks — forms, notifications, modals, dark mode out of the box.
Use: Full-featured apps, ship features fast.

**6. HeroUI (formerly NextUI)** — https://github.com/heroui-inc/heroui — ⭐ ~31k · Since 2021 · 🟢
Special: Modern beautiful defaults on Tailwind, React-Aria accessibility, auto dark mode, animations.
Use: Want a stunning look instantly with the least CSS work.

**7. Radix UI Primitives** — https://github.com/radix-ui/primitives — ⭐ ~19k · Since 2020 · 🔴
Special: Unstyled, WAI-ARIA-perfect primitives. It's the engine inside shadcn/ui.
Use: Building custom design systems with pro accessibility.

**8. Base UI** — https://github.com/mui/base-ui — ⭐ ~11k · 🆕 2024 · 🔴
Special: MUI team's newer actively-maintained primitive layer (shadcn/ui supports it). Modern Radix alternative.
Use: New projects wanting headless components with active maintenance.

**9. Headless UI** — https://github.com/tailwindlabs/headlessui — ⭐ ~29k · Since 2020 · 🟡
Special: Unstyled menus/dialogs/transitions by the Tailwind team.
Use: Tailwind projects needing simple accessible behavior.

**10. Magic UI** — https://github.com/magicuidesign/magicui — ⭐ ~22k · 🆕 2024 · 🟡
Special: Copy-paste animated components — marquees, bento grids, glowing beams, sparkles, text effects.
Use: Landing pages needing modern "wow" motion (pairs with shadcn/ui).

**11. Origin UI** — https://github.com/origin-space/ui-experiments — ⭐ ~1.4k · 🆕 2025 · 🟡
Special: Beautifully designed copy-paste page layouts & experiments (heroes, dashboards, pricing).
Use: Grabbing real polished section ideas fast.

**12. Syntax UI** — https://github.com/SyntaxUI/syntaxui — ⭐ ~1k · 🆕 2024 · 🟡
Special: Animated shadcn-style components (text effects, infinite sliders, accordions).
Use: Modern marketing pages; Magic UI alternative.

**13. Neobrutalism** — https://github.com/ekmas/neobrutalism-components — ⭐ ~5k · 🆕 2024 · 🟢
Special: Bold colorful neobrutalism-styled Tailwind components.
Use: Fun, personality-heavy sites & personal brands.

### 🅱️ React — big full kits
**14. MUI (Material UI)** — https://github.com/mui/material-ui — ⭐ ~99k · Since 2014 (🕰 classic, still king) · 🟡→🔴
Special: Massive mature component set + famous MUI X Data Grid, Material Design 3, huge ecosystem.
Use: Dashboards, admin panels, enterprise/data-heavy apps.

**15. Ant Design** — https://github.com/ant-design/ant-design — ⭐ ~99k · Since 2015 · 🟡→🔴
Special: Complete enterprise kit, best-in-class Tables & Forms.
Use: Complex CRUD admin backends, B2B/internal tools.

**16. React-Bootstrap** — https://github.com/react-bootstrap/react-bootstrap — ⭐ ~23k · Since 2013 · 🟢
Special: Bootstrap 5 components as real React components.
Use: Want Bootstrap's familiar look inside React.

**17. Blueprint (Palantir)** — https://github.com/palantir/blueprint — ⭐ ~22k · Since 2016 · 🟡→🔴
Special: Dense, powerful desktop-app-feel components (tables, overlays, datetime).
Use: Internal tools, data-heavy desktop-like web apps.

**18. Microsoft Fluent UI** — https://github.com/microsoft/fluentui — ⭐ ~20k · Since 2016 · 🟡→🔴
Special: Microsoft's own design system (Office/Windows look).
Use: MS-style products, Teams/Office add-ins, corporate tools.

**19. React Aria / Spectrum (Adobe)** — https://github.com/adobe/react-spectrum — ⭐ ~16k · Since 2019 · 🔴
Special: Research-grade accessibility & i18n on every widget.
Use: A11y-first products; hardest widgets (date pickers, comboboxes).

### 🅲 CSS-first / works with ANY framework
**21. Bootstrap** — https://github.com/twbs/bootstrap — ⭐ ~175k · Since 2011 · 🟢
Special: The classic — grid + components + JS. Most-starred CSS framework ever, endless templates.
Use: Not using Tailwind; want instant familiarity & max community help.

**22. Bulma** — https://github.com/jgthms/bulma — ⭐ ~50k · Since 2016 · 🟢
Special: Pure CSS, flexbox, clean modern classes, zero JS.
Use: Quick clean sites without JavaScript or build tools.

**25. Animate.css** — https://github.com/animate-css/animate.css — ⭐ ~83k · Since 2011 · 🟢
Special: One CSS class = fade/bounce/zoom animation.
Use: Quick attention animations without JS.

**26. 98.css** — https://github.com/jdan/98.css — ⭐ ~11k · Since 2020 · 🟢
Special: Fun, authentic Windows-98 retro UI.
Use: Retro/gaming/love projects & jokes that need to look period-correct.

### 🅳 Vue / Svelte / Angular / mobile
**27. Vuetify** — https://github.com/vuetifyjs/vuetify — ⭐ ~41k · Since 2016 · 🟢→🟡
Special: The full Material Design implementation for Vue.
Use: Vue apps wanting the Material look + huge component set.

**28. shadcn-vue** — https://github.com/unovue/shadcn-vue — ⭐ ~10k · Since 2023 · 🟡
Special: shadcn/ui ported to Vue (copy-paste philosophy, Reka UI primitives).
Use: Vue projects wanting the shadcn workflow.

**29. shadcn-svelte** — https://github.com/huntabyte/shadcn-svelte — ⭐ ~9k · Since 2023 · 🟡
Special: shadcn/ui for Svelte (Bits UI + Tailwind).
Use: Svelte/SvelteKit modern sites with full code ownership.

**30. Ionic Framework** — https://github.com/ionic-team/ionic-framework — ⭐ ~53k · Since 2015 · 🟡
Special: One codebase → web + iOS + Android apps.
Use: Hybrid mobile apps from web tech.
