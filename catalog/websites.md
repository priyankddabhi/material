# Websites — design and animation references

Websites to open when this repo does not have what you need. All links checked on 2026-10-30.
These are references to read, not files to copy. Check each site's terms before reusing anything from it.

| Site | Status | Use it for | Keywords |
|---|---|---|---|
| [Refero Styles](https://styles.refero.design/) | ✅ | Pick a real website's design system (colours, type, spacing) as a starting style; 2,000+ sites with DESIGN.md files | design system, DESIGN.md, colour palette, typography, spacing tokens, inspiration, real websites |
| [ThreeUI](https://threeui.com/browse?sort=recent) | ✅ | 3D hero sections, shader backgrounds, animated landing templates (heavy: 100–200 KB JS each). Free tier MIT, Pro paid | 3D, three.js, shaders, hero, animated background, landing page, WebGL |
| [shadcn/ui](https://ui.shadcn.com) | ✅ | Professional website components, themes, blocks and charts | components, themes, blocks, charts, React, professional |
| [GSAP](https://gsap.com) | ✅ | Main animation library docs: timelines, easing, stagger, SplitText, MotionPath, DrawSVG | animation, timeline, easing, stagger, text animation, SVG draw, motion path, video frames |
| [Anime.js](https://animejs.com) | ✅ | Docs for the GSAP alternative in `../libraries/anime/` | animation, SVG morph, stagger, timeline, lightweight |
| [SVG.js v3.2](https://svgjs.dev/docs/3.2/) | ✅ | Creating and animating SVG with short code | SVG, drawing, animation, shapes, gradients, masks |
| [IBM motion tips](https://www.ibm.com/design/language/animation/tips-and-techniques/) | ✅ | Motion design rules: one focal point, single-axis camera, small motion on dense designs | motion design, focal point, easing, transitions, principles |
| [U-Michigan motion](https://design-system.lib.umich.edu/visual-elements/motion/) | ✅ | Motion timing and easing rules from a real design system | motion, duration, easing, accessibility, reduced motion |
| [W3C SVG 2](https://www.w3.org/TR/SVG2/) | ✅ | The SVG standard (viewBox, paint, text, transforms); a Candidate Recommendation, not final | SVG, spec, viewBox, transforms, paint, text |
| [MDN `<animate>`](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Element/animate) | ✅ | Built-in SVG animation (SMIL) without any library | SVG animation, SMIL, animate, no library |
| [Figma Community](https://www.figma.com/community) | ⚠ blocks bots (403) — open in a browser | Free community design files, icon sets, plugins; check each file's licence | Figma, templates, icons, UI kits, plugins, inspiration |
