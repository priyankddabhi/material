# taste-skill classic — 12 extra design skills

Older skills from the taste-skill repo (version of 2026-09-26). The current repo ships only one skill, which is in [`../taste-skill/`](../taste-skill/); these 12 were removed from it later but are still useful. Each folder has a `SKILL.md` an agent can follow. `llms.txt` is the original one-line list of all skills.

| Folder | Skill name | What it does | Use it for | Keywords |
|---|---|---|---|---|
| [`brandkit/`](brandkit/) | brandkit | Image-generation skill for premium brand-kit boards: logo concepts, identity system, colour palette, typography, mockups | Brand identity for a client or product | brand kit, logo, identity, palette, typography, mockup |
| [`minimalist-skill/`](minimalist-skill/) | minimalist-ui | Clean editorial interfaces (Notion / Linear style), strict monochrome palette, flat bento grids | Calm, minimal, professional websites | minimalist, editorial, monochrome, bento, clean |
| [`soft-skill/`](soft-skill/) | high-end-visual-design | Expensive, soft UI: premium fonts, whitespace, depth, smooth animation | Luxury / premium look | premium, luxury, soft, whitespace, depth, rich look |
| [`redesign-skill/`](redesign-skill/) | redesign-existing-projects | Audits an existing site, finds generic AI patterns, fixes the design | Upgrading a site you already have | redesign, audit, upgrade, fix design |
| [`brutalist-skill/`](brutalist-skill/) | industrial-brutalist-ui | Raw mechanical UI: Swiss typography, military-terminal look, extreme scale contrast (beta) | Bold, raw, technical style | brutalist, Swiss, terminal, raw, bold |
| [`gpt-tasteskill/`](gpt-tasteskill/) | gpt-taste | Awwwards-level frontend design with GSAP motion; AIDA page structure | Premium animated landing pages | GSAP, motion, Awwwards, landing page, AIDA |
| [`image-to-code-skill/`](image-to-code-skill/) | image-to-code | Generates a design image first, analyses it, then codes the site to match | Image-first website building | image to code, reference image, implementation |
| [`imagegen-frontend-web/`](imagegen-frontend-web/) | imagegen-frontend-web | Image-only skill: premium website design reference images (no code) | Website mockups / concepts | website mockup, design reference, image generation |
| [`imagegen-frontend-mobile/`](imagegen-frontend-mobile/) | imagegen-frontend-mobile | Image-only skill: premium mobile app screens and flows (no code) | App screen concepts | mobile app, screens, flows, iOS, Android |
| [`stitch-skill/`](stitch-skill/) | stitch-design-taste | Google Stitch-compatible design rules; includes a `DESIGN.md` | Generating a DESIGN.md / Google Stitch UI | Google Stitch, DESIGN.md, design system |
| [`output-skill/`](output-skill/) | full-output-enforcement | Stops the AI from skipping code or leaving placeholders | Long code outputs | complete output, no placeholders |
| [`taste-skill-v1/`](taste-skill-v1/) | design-taste-frontend-v1 | The original v1 of taste-skill (variance / motion / density dials) | Projects that relied on v1 behaviour | taste, v1, dials |
