# Skills — design instructions for AI agents

Each skill is a folder with a `SKILL.md` an agent reads and follows. Our own rules in [`../guides/`](../guides/README.md) win when they disagree.

| Skill | What it gives you | Use it for | Keywords | Licence |
|---|---|---|---|---|
| [`impeccable/`](impeccable/) | Design vocabulary: `SKILL.md` + 42 playbooks in `reference/` (adapt, animate, audit, bolder, clarify, colorize, critique, delight, distill, harden, layout, polish, quieter, typeset, visualize…) | Making a UI look professional; critiquing and fixing AI-made pages | design rules, anti-slop, polish, critique, typography, colour, layout, hierarchy | Apache-2.0 |
| [`taste-skill/`](taste-skill/) | "design-taste-frontend": art direction distilled from 247 award-gallery sites (idea, composition, type, palette, photos, section blueprints) | Websites that look art-directed, not generic | taste, art direction, composition, palette, landing page, portfolio | MIT |
| [`taste-skill-classic/`](taste-skill-classic/README.md) | **12 extra skills** from the older taste-skill: **brandkit** (brand-kit boards), **minimalist** (editorial monochrome), **soft** (expensive premium look), **redesign** (audit + upgrade a site), brutalist, gpt-taste (GSAP landing pages), image-to-code, imagegen web / mobile mockups, stitch (DESIGN.md), output enforcement, taste v1 | Brand identity, a specific style, redesigning an existing site, mockups | brand kit, minimalist, premium, luxury, redesign, brutalist, mockup, DESIGN.md | MIT |
| [`anthropic/frontend-design/`](anthropic/frontend-design/) | Guidance for distinctive, intentional visual design | Choosing an aesthetic direction and typography for a UI | aesthetic direction, typography, distinctive UI | Apache-2.0 |
| [`anthropic/canvas-design/`](anthropic/canvas-design/) | Posters, art and static designs as PNG/PDF, with **29 font families** in `canvas-fonts/` | Product ads, posters, static infographics, thumbnails | poster, static design, PNG, PDF, composition, fonts | Apache-2.0 · fonts OFL |
| [`anthropic/theme-factory/`](anthropic/theme-factory/) | **10 ready themes** (colours + fonts) in `themes/`: arctic-frost, botanical-garden, desert-rose, forest-canopy, golden-hour, midnight-galaxy, modern-minimalist, ocean-depths, sunset-boulevard, tech-innovation | Styling slides, docs, reports, landing pages in one step | theme, palette, font pairing, preset | Apache-2.0 |
| [`anthropic/algorithmic-art/`](anthropic/algorithmic-art/) | Generative art with p5.js: flow fields, particles, seeded randomness | Unique abstract backgrounds and visuals | generative art, p5.js, flow field, abstract background | Apache-2.0 |
| [`brand-styles/`](brand-styles/) | **84 brand design systems**, one folder each with `DESIGN.md` (Apple, Stripe, Vercel, Linear, Notion, Airbnb, Nike, Tesla, Spotify, Ferrari, Starbucks, PlayStation…) | Picking a style direction (colours, type, spacing, components) | brand style, design system, DESIGN.md, premium, luxury, tech | MIT |

Brand styles describe real companies: use them for direction, never to imitate a brand's identity.
`anthropic/THIRD_PARTY_NOTICES.md` holds the notices that come with the Anthropic skills.
