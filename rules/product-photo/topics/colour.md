# COLOUR — mind topic

## REEL-002 — 2026-10-29 — reel De37Qbfodht (accent colour teaching)
RULE: A good two-colour base + ONE unexpected accent colour = memorable.
Good alone is forgettable; the surprise third colour makes it stick.
APPLY IN PROMPT: "base palette of two good colours + exactly one
unexpected accent colour on one element only (one prop, one word, one
detail) — never two accents, never accent everywhere."
APPLY IN FRAME: CTA or one headline word may carry the accent colour;
everything else stays in the base palette.
CHECK: count accent-coloured elements. More than one focal accent = the
surprise is gone, redo. Examples: yellow+black+purple reads bold;
brown+gold+amber reads rich.

## GIT-003 — 2026-10-29 — beiko-lab training_resources GitHub wiki
SOURCE: https://github-wiki-see.page/m/beiko-lab/training_resources/wiki/Graphic-Design-(Posters-Figures-Presentations)
RULE: One consistent limited palette per ad. Important elements highlighted,
cruft faded out. Prefer colourblind-safe palettes.
APPLY IN PROMPT: "palette: max 3 colours — muted background + product tones
+ one accent; no rainbow props."
CHECK: count colours in the demo. More than 3 strong colours = redo.

## REEL-004 — 2026-10-29 — reel De9MnRho88a (palette + one effect)
RULE: A restrained two-colour palette becomes memorable with just ONE
extra: one contrasting accent colour OR one striking visual effect.
Never more colours, never two effects.
EXTENDS REEL-002: the surprise third element does not have to be a
colour — it can be an effect: inflated balloon/gloss shapes, metallic
chrome finish, frosted glassmorphism panels.
EXAMPLES FROM THE REEL: hot pink + white + electric lemon balloon
shapes = impossible to ignore; pearl grey + mint + chrome silver =
striking; obsidian black + ice blue + frosted glass = premium.
APPLY IN PROMPT: "two-colour base + ONE effect only: frosted-glass panel
behind the label, OR one metallic prop, OR one glossy inflated shape.
Never two effects together."
APPLY IN FRAME: keep the cream frame clean — the effect lives in the
photo, not in extra frame decoration.
CHECK: count the extras. One accent/effect = memorable. Two or more =
clutter, remove one.
