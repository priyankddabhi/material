# PROMPT CRAFT — mind topic

## WEB-004 — 2026-10-29 — AI product photography skill (prompt formula)
SOURCE: https://deepwiki.com/inference-sh/skills/7.5-ai-product-photography
RULE: Build every generation prompt in this order: [Product] +
[Setting/Background] + [Lighting] + [Style] + [Technical]. Missing slots
= random results.
APPLY: write the prompt as five slots every time, e.g. "glass jar candle
+ dark charcoal surface + three-point light + luxury editorial + sharp
focus, photorealistic." Never a one-line vague prompt.
CHECK: read the prompt back — if any slot is empty, fill it before
generating.
